# Retail Sales Analysis | SQL Server

## Project Overview
An end-to-end SQL project focused on analysing retail sales data to uncover business trends, evaluate performance, and generate actionable insights.

The project uses Microsoft SQL Server to explore, clean, validate, and analyse retail sales data across multiple business dimensions.

## Dataset Overview
- **Domain:** Retail Sales
- **Time Period:** 2022–2025
- **Records:** Approximately 18,000
- **Columns:** 36

The dataset includes information about sales transactions, customers, products, stores, regions, discounts, returns, payments, shipping, and inventory.

## Tools & Technologies
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

## Project Workflow

1. **Data Exploration** – Examining the dataset structure, records, and column details.
2. **Data Quality Assessment** – Identifying missing values, duplicates, and inconsistent records.
3. **Data Cleaning** – Handling data quality issues and standardising values.
4. **Data Validation** – Verifying the accuracy and consistency of cleaned data.
5. **Business Analysis** – Analysing sales, profitability, customers, products, regions, and operational performance.

## Business Analysis Areas
- Overall Sales & Profitability
- Yearly and Monthly Performance
- Regional Performance & Growth
- Product and Category Analysis
- Customer Behaviour & Segmentation
- Discount and Promotion Analysis
- Sales Channel and Store Performance
- Return and Delivery Analysis
- Inventory and Payment Analysis

## SQL Concepts Used
- Aggregate Functions
- GROUP BY and HAVING
- Joins and Subqueries
- CASE Statements
- Common Table Expressions (CTEs)
- Window Functions
- Ranking Functions
- Date Functions
- Stored Procedures
- Data Cleaning and Validation

## Objective
To demonstrate practical SQL skills by transforming raw retail data into meaningful business insights and supporting data-driven business decisions.
